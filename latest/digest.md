## 1. ZEST: Zero-shot embodied skill transfer for athletic robot control
- Venue: Science Robotics
- Published: 2026-08-12
- Type: direct
- Tags: humanoid, locomotion
- Score: 0.7275
- Core insight: ZEST把动作捕捉、单目视频重建和关键帧动画统一为可追踪的参考轨迹，用一套单阶段强化学习配方训练机器人在硬件上直接执行；其“零样本”指仿真训练后不再做真实机器人微调，而非对未见动作的零样本学习。
- Problem frame: 敏捷全身动作同时受高自由度、间歇多点接触、执行器限制和仿真—现实误差影响。既有方案往往依赖每项动作的接触标注、状态估计、复杂奖励或人工调参，且来自视频的动作本身还带有抖动、滑步等误差。
- First principles: 参考动作提供行为先验，策略无需从零发现每种动作；但参考并不必被刚性复现。将参考作为前馈目标、由策略学习小幅残差，并把训练资源集中到最难的动作阶段，能在保留动作风格的同时为真实动力学和接触误差留出修正空间。
- Mechanism: MoCap和视频动作先经运动学重定向到目标机器人；Actor只接收即时本体感知、上一动作和下一时刻参考状态，输出叠加在参考关节角上的残差目标，Critic在仿真中额外使用特权状态。轨迹被分段，按近期失败率自适应重采样；对高动态片段施加基于模型的虚拟基座力矩并随跟踪改善退火至零。闭链执行器则用近似臂架模型确定仿真参数和PD增益，并配合中等强度域随机化。
- Boundary advanced: 论文在Atlas、Unitree G1和Spot三种平台展示多接触、人形视频迁移和四足特技。硬件实验实际采用“每个目标动作一套专用策略”，约训练10小时后直接部署；多技能策略仅用于仿真分析。尚未验证对训练分布外新动作的泛化，当前策略依赖本体感知、平坦且不打滑的环境，并仍要求足够合理的系统建模。
- Old problem: 传统全身MPC通常需要预先给定接触时序和可接触末端，面对膝、躯干、前臂等任意身体接触及视频重建的错误接触时序会变得脆弱；从零强化学习又容易受奖励设计和早期失败影响。
- Why it works: 失败率驱动的分段采样避免长轨迹中困难片段被平均掉，辅助力矩降低早期翻倒造成的无效探索，之后自动撤除以避免依赖外力；残差动作把主要轨迹跟踪交给参考与PD回路，让策略专注补偿模型偏差。消融显示，去除课程或自适应采样会降低成功率或样本效率，绝对动作和移除Critic特权信息也会削弱鲁棒性。
- True novelty: 新意不在于单独使用模仿学习、域随机化或辅助力，而在于以较少的任务特定组件，把不等质量的MoCap、手机视频和动画放进同一套低调参、单阶段训练与硬件部署配方，并在全尺寸人形、小型人形和四足平台上给出实机证据。
- Evidence: 硬件结果覆盖Atlas的步行、滚翻、匍匐、侧手翻和霹雳舞，G1的视频舞蹈与跳箱、上下箱，以及Spot的倒立、连续后空翻和滚转。视频动作即使含姿态抖动和滑步，Atlas若干动作的关节与姿态平均误差约为0.05 rad；G1上下箱在名义条件下各连续5次均成功，训练分布内的横向位置和偏航扰动也均成功。15动作多技能仿真消融显示完整方法在10小时训练时具有更高平均成功率和更好的低尾部表现；与MPC的比较仅在仿真、且只覆盖部分动作。

## 2. OopsieVerse: A Safety Benchmark with Damage-Aware Simulation for Robot Manipulation
- Venue: arXiv
- Published: 2026-06-30
- Type: direct
- Tags: manipulation
- Score: 0.86
- Core insight: OOPSIEVERSE把仿真中通常被忽略的物理损伤显式表示为逐对象累积的健康状态，使“完成任务”与“安全完成任务”成为可分离、可训练和可比较的目标。
- Problem frame: 家用操作仿真通常只奖励目标达成，因此机器人可以通过撞击、挤压、过热或泼液等现实中不可接受的捷径获得成功。关键约束是：如何利用普通机器人仿真器已有的交互信号，构造可跨任务复用且不依赖逐任务手工约束的损伤度量。
- First principles: 物体损伤往往由超过材料耐受阈值的接触、温度或液体暴露累积而成，并具有不可逆后果。若按对象和连杆持续记录这些超过阈值的暴露，便可把安全代价纳入原有决策过程，而无需改写任务本身的动力学。
- Mechanism: DAMAGESIM在原有POMDP状态上加入逐对象健康变量：机械损伤以接触力相对加速度方向的分量近似冲击与持续载荷，热损伤由温度越过对象阈值计算，液体损伤由接触液体颗粒超过阈值计算；各类损伤逐步扣减连杆健康，物体健康取其连杆最小值。该状态可作为观测、奖励惩罚或终止条件接入策略；OOPSIEBENCH再用跨OmniGibson与RoboCasa的任务暴露“成功但有损伤”的捷径。
- Boundary advanced: 论文在两种不同物理后端上实例化该框架，并给出32个任务实例、21种任务设计，用于人类示教、模仿学习、强化学习、VLA评测及两项sim-to-real测试。它仍是物理损伤的近似模型；热与液体损伤实现仅限OmniGibson，且新对象需要用户设定每对象或每连杆参数。
- Old problem: 现有家庭操作基准大多只报告任务完成率；安全信息要么缺失，要么依赖碰撞等抽象代价或逐任务奖励塑形。这样既难比较不同任务的风险，也会掩盖策略以破坏性动作换取成功的情况。
- Why it works: 统一健康信号让同一条交互轨迹同时可被评测、展示给示教者、用于筛除不安全数据，并转化为RL的惩罚项。安全完成率要求任务成功且所有对象健康保持在阈值之上，因此能直接揭示传统完成率看不到的安全缺口。
- True novelty: 真正的新意不是提出一种新的安全RL算法，而是将可编辑、对象中心、跨模拟器的损伤近似模型，与专门设计了不安全捷径的家庭操作基准打包，并在数据收集、IL、RL、VLA评测和真实迁移中复用同一安全表示。
- Evidence: 五个IL任务每项结果基于30次rollout：例如未过滤的Wipe Countertop策略任务完成率为100%，安全完成率仅35%。在RL中，Shelve Cereal Box的DSRL安全完成由13%升至33%，Move Cup of Water微调由20%升至100%，Place Plate从头训练加入损伤惩罚后安全完成超过80%，而仅任务奖励接近0%。真实Franka两任务、每方法每任务10次试验中，损伤过滤策略为75%任务完成、65%安全完成、15%不安全行为，对照为70%、5%、75%；硬件安全结果为人工可观察损伤的定性判定。

## 3. SIMPLE: Simulation-Based Policy Learning and Evaluation for Humanoid Loco-manipulation
- Venue: arXiv
- Published: 2026-06-06
- Type: direct
- Tags: humanoid
- Score: 0.86
- Core insight: SIMPLE将接触丰富的全身动力学与高保真视觉渲染拆分给MuJoCo和Isaac Sim，再用统一接口、任务和数据管线连接起来，使人形全身移动操作的训练与评测能够规模化且可重复。
- Problem frame: 真实人形评测需要频繁复位、人工操作和重型硬件，难以公平复现；既有模拟基准又往往在“稳定接触与平衡”或“多样物体、场景与视觉”之间二选一，无法同时覆盖全身移动操作。
- First principles: 一个能预测现实表现的模拟评测，不只需要逼真的图像或物理之一，而要让接触、平衡、动作接口、视觉分布和成功判据共同构成可比较的闭环。把各自擅长的物理和渲染解耦，并在状态同步后统一评测，能避免单一引擎同时承担两类约束。
- Mechanism: MuJoCo负责刚体动力学、接触求解和控制，Isaac Sim同步机器人与环境状态并进行光线追踪渲染；高层策略输出上身运动学目标和底座导航命令，较高频的下身跟踪控制器维持平衡。平台提供60个任务、50个室内场景和千余资产，并用运动规划与低延迟VR遥操作采集轨迹，再离线重放、随机化材质、光照、相机、物体与布局来训练和评测策略。
- Boundary advanced: 平台把单臂或轮式机器人基准难以覆盖的整身移动、接触与物体交互放到同一测试床中，并纳入VLA、世界动作模型和模仿学习模型。作者只在相似布置的拿放和交接两类任务验证零样本实机迁移；当前仅建模刚体，布料、绳索和食物等可变形物体不在能力范围内，单GPU光线追踪约4帧/秒也限制规模。
- Old problem: 人形策略通常直接在现实中比较，成本高且难复现；模拟平台则要么偏桌面操作、缺少全身移动和平衡，要么偏步行、缺少物体、室内场景及视觉多样性，导致不同策略的结果难以在同一条件下解释。
- Why it works: 双模拟器让接触稳定性不被高质量视觉渲染牺牲，离线渲染与域随机化则把同一条物理轨迹扩展到多种观察条件；固定的动作与评测接口减少模型间的工程差异。实验中，混合随机化训练将BendHandover在更难视觉设置上的成功率从0.50提高到0.80，说明视觉分布覆盖是该闭环有效的关键。
- True novelty: 贡献不只是新增任务集，而是把人形全身移动操作所需的物理、渲染、数据采集、下身控制器接入和分级评测协议整合为同一套可扩展基础设施；作者将其定位为面向该任务的首个全面全栈模拟测试床。
- Evidence: 论文在6个代表任务、3个随机化等级上比较多类VLA、世界动作模型与模仿学习基线，并报告模拟中的模型排序与既有实机报告相近。仿真VR遥操作在三个代表任务中为每小时310.3、197.8、156.5条示范，高于实机遥操作的206.8、130.9、87.2条。只用模拟数据训练的单一Ψ0策略在拿放任务中模拟为9/10、实机8/10，在交接任务中模拟10/10、实机8/10；这支持有限设置下的迁移，不能外推为广泛现实可靠性。

## 4. Controlled flight of high-thrust ultralight ion-propelled microrobot with integrated sensing
- Venue: Nature Communications
- Published: 2026-08-08
- Type: direct
- Tags: micro_robot
- Score: 0.48
- Core insight: 把离子风推进从只能起降或停留在理论控制的超轻平台，推进为可由IMU闭环稳定、并能带传感载荷执行任务的微型飞行机器人。
- Problem frame: 离子风推进没有旋翼或扑翼，但微机器人长期受限于推重比、有效载荷和多自由度姿态可控性；低惯量又会把微小推力波动放大为明显姿态偏差。
- First principles: 高压电晕放电使离子在电场中加速，并通过与中性空气碰撞传递动量形成离子风；四个推进单元的差分推力可产生姿态力矩，而IMU反馈用于抑制低惯量系统的偏航和扰动。
- Mechanism: 机器人以金属化PET复合结构减重，四组交叉布置的电流体动力离子风推进器提供推力；中心柔性PCB上的IMU反馈姿态，闭环调节各推进器电压完成姿态稳定及方形、三角形轨迹跟踪。相机和FBG光纤传感器作为载荷分别用于成像和接触式材料辨识。
- Boundary advanced: 论文实证了系留条件下的闭环飞行、载荷兼容性和预设轨迹，并非已完成电池供电的完全无系留飞行、传感器驱动的自主决策或多机群体协同。
- Old problem: 既有离子推进微机器人往往只有基本起降、被动稳定或仿真控制；提高电压虽可增推，却受安全与工程约束，且传统硅或金属制造和脆弱装配不利于低成本批量化。
- Why it works: 轻质结构和优化的发射极—收集极几何同时改善质量与离子风效率，留下传感与控制载荷空间；IMU闭环把难以精确建模的环境与推力波动转化为可校正的姿态误差。
- True novelty: 新意不只是离子风产生升力，而是把高推重比、低成本可折叠制造、惯性闭环控制和两类传感载荷放进同一36.7 mg平台，并以飞行任务验证其耦合可行性。
- Evidence: 原型尺寸为37.7 × 37.7 mm、质量36.7 mg，推重比为5:1；闭环后俯仰与横滚RMSE分别下降83.11%和89.21%，姿态振荡限制在±5°、稳态误差为0.50°和1.03°。带载测试稳定飞行超过15分钟，无载荷连续系留飞行1小时；相机获得连续环境图像，FBG接触测量以波长位移区分材料类型。

## 5. Nonlinear spectral modeling and control of soft-robotic muscles from data
- Venue: Nature Communications
- Published: 2026-09-16
- Type: direct
- Tags: none
- Score: 0.5175
- Core insight: 利用慢谱子流形把HASEL软体肌肉的高维、多物理场和滞回动力学压缩为可从受迫轨迹直接学习的输入—状态关系，再以其逆模型配合PI反馈实现实时关节控制。
- Problem frame: 电液或静电软体肌肉具有顺应性和高性能，却受材料、流体、静电、摩擦与离合器耦合影响，存在记忆效应和滞回；精确物理建模既依赖难以测准的参数，也难覆盖装配误差和系统级交互。
- First principles: 当外部输入变化慢于执行器内在瞬态时，状态会快速收敛到低维慢流形；在这一绝热条件下，可用受迫响应数据学习输入到状态的映射，并求逆得到前馈控制输入。
- Mechanism: 作者从强迫响应轨迹学习多项式慢流形映射x=g(u)，避免大步阶衰减实验诱发的非代表性滞回；将逆慢流形模型作前馈，再与PI反馈结合以补偿残余误差和扰动，控制由拮抗HASEL人工肌肉与静电离合器构成的关节。
- Boundary advanced: 证据来自一个拮抗HASEL—离合器关节、给定饱和与变化率约束下的随机轨迹；慢流形近似依赖明显的时间尺度分离，不能据此推断对所有软体执行器、快速激励或任意多自由度系统都同样有效。
- Old problem: 仅靠反馈会受非线性和迟滞拖累，单独前馈又无法抵抗扰动；传统降阶或连续体模型则通常需要详细材料与几何参数，难在实际装配后的系统上快速辨识。
- Why it works: 该方法不试图逐项还原全部物理机理，而是利用快速瞬态已收敛这一结构，把实际系统的耦合和装配偏差留在数据中；逆模型负责主要轨迹，PI环路校正未建模部分。
- True novelty: 其关键不是一般黑箱拟合，而是以谱子流形理论限定可学习的低维结构，并用受迫数据直接形成可逆的控制模型，连接了可解释降阶、数据采集和闭环控制。
- Evidence: 在相同饱和和变化率限制的随机测试轨迹上，逆SSM+PI的RMS跟踪误差为2.38°、最大误差10.41°；仅前馈分别为3.63°和16.67°，仅PI反馈为7.63°和26.00°。论文还明确比较了三种控制策略，支持联合方案的优势。

## 6. Real-world humanoid locomotion with reinforcement learning
- Venue: Science Robotics
- Published: 2024-04-17
- Type: direct
- Tags: humanoid
- Score: 0.654
- Core insight: 把本体感觉与既往动作序列作为隐含环境估计，让因果Transformer在不更新权重的情况下，根据上下文调节双足步态，实现仿真训练到全尺寸人形机器人实机的零样本迁移。
- Problem frame: 人形步行面对地形、摩擦、载荷和外扰等部分可观测变化；经典控制器可在特定设定中表现稳健，却难将环境变化和模型偏差快速泛化到真实世界。
- First principles: 历史中的期望—实际状态偏差及动作后果包含接触、地形和动力学的隐含信息。因果注意力可从这些时间依赖中形成上下文表征，因此策略无需在线梯度更新，也能改变下一步动作。
- Mechanism: 先在大规模随机化仿真中训练可见完整状态的教师策略，再用教师模仿与强化学习共同训练只接收观测—动作历史的学生策略。部署时，因果Transformer以长度16的上下文预测下一动作；训练后直接零样本迁移到Digit实机。
- Boundary advanced: 论文展示的是不依赖相机等外感知的行走适应，而非对台阶或障碍物的提前视觉规划；作者也报告左右不对称、速度跟踪并不完美，极强外力例如拉拽电缆仍可能使机器人跌倒。
- Old problem: 将环境参数显式估计再交给控制器会增加建模与调参负担；只在单一仿真条件中训练的策略也容易把未见地形、载荷或接触事件当作分布外失败。
- Why it works: 随机化仿真提供广泛动力学与环境变化，历史窗口让策略在部署时从自身运动后果推断当前情境；Transformer的时序注意力由此把快速的上下文适应和动作预测合并到一个策略内。
- True novelty: 关键推进是将全尺寸人形的真实世界步行视为带记忆的部分可观测控制问题，而不是仅靠当前状态或在线微调；历史驱动的Transformer成为隐式适应器。
- Evidence: 45 kg、约1.6 m的Digit在完全仿真训练后零样本部署到广场、人行道、跑道和草地等室外环境；论文报告一周全天户外测试未观察到跌倒。实机还完成外力干扰、室内粗糙地面、斜坡和五类载荷测试；在高保真仿真中，跨10次运行的成功率比较显示其在台阶和不稳定地面优于厂商控制器。

- Why it works: 层次分解先把复杂连续关节控制压缩为可复用的推进或转向技能，再让高层仅处理趋化决策；以局部压力和浓度构造奖励与观测，使策略可在部分可观测状态下学习，而形态对称性还减少了需独立学习的原语数量。
